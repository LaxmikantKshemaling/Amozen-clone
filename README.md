# Amazon Clone

## Overview

Amazon Clone is a full-stack e-commerce web application inspired by Amazon. The application allows users to browse products, search for items, manage shopping carts, place orders, and manage their accounts through a user-friendly interface.

The project was developed to gain hands-on experience in Java Full Stack Development using Java, JDBC, Servlets, JSP, MySQL, and modern software design patterns.
